# Changelog

All notable changes to Little Growth Planet are documented in this file. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses semantic versioning.

## [Unreleased]

### Planned

- Authentication guidance for Internet-facing self-hosted deployments.
- Guided backup and restore validation.
- Broader export, reading-plan, and accessibility test coverage.

## [1.0.0] - 2026-08-11

### Added

- Daily check-ins for recurring, date-range, and temporary tasks.
- Monthly matrix with category colors, historical editing, and points summaries.
- Monthly and annual Excel exports with one worksheet per month and status filters.
- Configurable points, reward catalog, redemptions, and redemption history.
- Monthly reading plans, editable daily page ranges, progress tracking, and a personal library.
- Optional AI-assisted homework review, annotations, mistake collection, and printable practice sheets.
- SQLite API, AI provider configuration, public deployment documentation, and environment examples.
- State validation, optimistic version checks, server-sent update events, and regression tests.
- GitHub Actions for CI, releases, and transparent roadmap issue creation.

### Changed

- Rebranded the public project as Little Growth Planet.
- Replaced personal defaults and deployment-specific references with generic public examples.
- Updated the README with English-first bilingual documentation and sanitized product screenshots.

### Security

- Removed private deployment handoff information from the current public tree.
- Added a security reporting policy and documented the current single-family security boundary.
- Updated audited dependencies to versions with no known npm audit findings at release time.
