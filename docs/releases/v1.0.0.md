# Little Growth Planet v1.0.0

The first public release of Little Growth Planet provides a self-hosted system for primary-school homework, reading plans, daily-life habits, points, rewards, and long-term review.

## Highlights

- Daily check-ins with completion quality, notes, required-task tracking, and points.
- A monthly matrix plus polished monthly and annual Excel exports.
- Reading plans with editable daily page ranges, progress, and completion rewards.
- A configurable reward catalog and complete redemption history.
- Optional AI-assisted homework review and mistake collection.
- Local SQLite storage with versioned writes and state validation.
- English-first bilingual documentation, sanitized screenshots, CI, and regression tests.

## Quick Start

```bash
npm ci
npm test
npm run server
npm run dev
```

The API listens on `127.0.0.1:8090` by default. See the [README](https://github.com/yyshi127/homework/blob/v1.0.0/README.md) and [self-hosting guide](https://github.com/yyshi127/homework/blob/v1.0.0/docs/DEPLOYMENT.md) for configuration.

## Important Security Boundary

This release uses a single-family data model and does not include built-in authentication or tenant isolation. Do not expose it directly to the public Internet without an authentication layer or equivalent access control.
